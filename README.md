# 래미안베라힐즈 민원관리시스템

개발가이드.txt 를 기준으로 만든 1단계(웹앱) 결과물입니다.

## 포함 파일
- `index.html` — 메인 앱 (대시보드 / 민원이력 / 동·호수관리 / 공용부관리 / 민원유형관리 / 백업복원)
- `manifest.json` — 홈 화면에 앱처럼 추가하기 위한 PWA 설정
- `icon-192.png`, `icon-512.png` — 앱 아이콘(파비콘)

## 최초 데이터
- 동·호수관리에 **래미안베라힐즈 1,305세대**(201동~220동)가 첨부해주신 엑셀
  파일(`세대(동호수)_래미안베라힐즈.xlsx`) 기준으로 이미 일괄등록되어 있습니다.
  브라우저에서 `index.html`을 처음 열면 자동으로 세팅됩니다.
- 공용부는 주차장/화단·조경/놀이터/커뮤니티/기타 기본 1건씩과, "아파트 각 동"
  카테고리에 201동~220동 20건이 자동 등록되어 있습니다.
- 민원유형 기본값: 층간소음, 누수, 주차, 시설물 고장, 조경/청소, 안전/보안, 기타
  (관리자 화면에서 자유롭게 추가·삭제 가능)

## 관리자 계정
- 기본 비밀번호: `admin1234`
- 사이드바 하단 "관리자 로그인"으로 로그인하면 등록/수정/삭제가 가능해지고,
  로그인하지 않으면 조회만 가능합니다(가이드 3번 요건).
- 로그인 후 "백업/복원" 화면 하단에서 비밀번호를 바꿀 수 있습니다. **배포 전에
  반드시 변경하세요.**
- ⚠️ 현재 방식은 브라우저 안에서만 검사하는 간단한 잠금장치입니다. 실제 보안이
  필요하면 아래 4단계(Firebase)에서 Firebase Authentication + 보안 규칙으로
  교체하는 것을 권장합니다.

## 현재 동작 방식 (오프라인 모드)
지금 버전은 각 기기(브라우저)의 저장공간에 데이터를 저장합니다. 즉 내 컴퓨터에서
등록한 민원이 다른 사람 기기에는 자동으로 보이지 않습니다. 개발가이드 순서상
1단계(웹앱)만 완료된 상태이며, 2~4단계를 진행하면 실시간 공유가 가능합니다.

## 다음 단계 (개발가이드 2~4단계)
1. **GitHub 업로드**: 이 폴더(`index.html`, `manifest.json`, 아이콘 파일)를 새
   GitHub 저장소에 올립니다.
2. **Netlify 배포**: Netlify에서 해당 저장소를 연결하면 자동으로 배포되고,
   `xxx.netlify.app` 주소가 생성됩니다. (레퍼런스 사이트와 동일한 방식)
3. **Firebase 연동**: Firebase 콘솔에서 프로젝트를 만들고 Firestore(실시간
   데이터베이스)를 활성화한 뒤, 발급받은 설정값(apiKey 등)을 알려주시면
   `index.html`의 localStorage 저장 로직을 Firebase Firestore 실시간 동기화
   로직으로 교체해 드릴 수 있습니다. 이 작업이 끝나면 여러 기기·여러 사람이
   동시에 같은 데이터를 보고 편집할 수 있고, 관리자 인증도 Firebase Auth로
   강화할 수 있습니다.

## 세대 엑셀 재일괄등록
"동·호수관리" 화면의 "엑셀 일괄등록" 버튼으로 언제든 엑셀 파일을 다시 올릴 수
있습니다. 파일 첫 시트에 `연번`(선택), `동`, `호`(또는 `호수`) 열이 있으면
자동으로 인식합니다. "기존 유지+추가"와 "전체 교체" 두 가지 방식을 선택할 수
있습니다.
